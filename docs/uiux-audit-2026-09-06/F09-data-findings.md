## 4. 店舗サイトの外形監査でわかったこと（2026-09-13 追記）

### 4-1. 教訓：HTTPの結果は「閉店」の根拠にならない

`check_shop_sites.mjs` の1回目・2回目の結果には**誤検知が大量に混ざっていました**。

| 出た症状 | 実際 |
|---|---|
| `fetch` がタイムアウト（43件） | 21店は営業中。Lynx 11店を含む |
| `ERR_BLOCKED_BY_CLIENT` | 手元の広告ブロック拡張が遮断しただけ |
| `403 Forbidden`（7店） | サーバーがbotを弾いているだけ。営業中 |
| `401`（2店） | 認証・年齢確認のゲート。営業中 |
| 証明書エラー（19店） | 設定不備。サイトは生きている |
| `ERR_ABORTED` | **利用者から指摘**。`richaroma.nagoya` は普通に見られる |

**「相手が応答しない」と「店が無い」は別物です。** 前者は相手の都合・こちらの環境・
ネットワークのどれでも起きます。これを根拠に店を消すと、営業中の店を消します。

### 4-2. 信用できる唯一の信号＝DNS

ドメインが**登録されていない**（NSレコードすら引けない）ことだけは、相手のbot対策にも
こちらの拡張にも左右されません。**利用者の端末とは別のネットワークから**全785ホストを
名前解決した結果：

- 🔴 **ドメインが登録されていない：17ホスト / 19店**
- 🟠 ドメインは保有しているがAレコードが無い：1ホスト / 1店（`prispa.jp`）
- ✅ 生きている：767ホスト / 1,069店

うち2店（`bellrose-osaka.com` / `wife-room.com`）は、HTTPでは「タイムアウト」に
埋もれていました。1店（`kyupito-wakayama.net`）は **09-09時点でHTTP 200を返していた**のに
09-13には失効しています。**監査結果は数日で古くなります。**

### 4-3. 道具の直し（反映済み）

- 名前解決の段を追加し、**DNSの判定を最優先**にした
- 「ドメイン消滅」と「証明書エラー」「拡張のブロック」を別の箱に分けた
- ブラウザで正常だったURLを「消してはいけない」と明示して一覧に出す
- 一覧に出ない判定が出たら「未分類」として警告する
